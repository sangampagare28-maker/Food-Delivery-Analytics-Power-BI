# Food Delivery Analytics Dashboard | Power BI
## 1. Project Overview
This project focuses on analyzing food delivery business performance using Microsoft Power BI.
The dashboard provides insights into food quantity, transaction sales, average sales, payment methods, delivery status, and monthly performance.
The objective is to help management understand business performance and make data-driven decisions.
## 2. Tools & Technologies
- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel
- Data Visualization
## 3. Dashboard KPIs
- Total Quantity
- Transaction Sales
- Average Sales
## 4. Key Analysis
### Monthly Performance
Analyzed monthly food quantities and transaction sales trends.
### Food Category Analysis
Compared Gold and Regular categories across different food types.
### Food-wise Analysis
Identified the highest-selling food items based on total quantity.
### Payment Method Analysis
Analyzed transactions through:
- UPI
- Cash on Delivery (COD)
- Card
### Delivery Status Analysis
Compared delivered and cancelled orders.
## 5. Key Business Insights
1. February recorded the highest monthly quantity at approximately 8.8K.
2. UPI is the leading payment method.
3. Samosa recorded the highest quantity among the displayed food items.
4. The dashboard provides a comparison of Gold and Regular food categories.
5. Delivery status analysis helps monitor order fulfillment performance.
